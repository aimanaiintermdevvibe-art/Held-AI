HELD AI CHATBOT - WORK SUMMARY
As of 2026-11-19
==================================================

1. WHAT IS BUILT
----------------
- Four-agent pipeline (Gemini gemini-3.5-flash-lite): Agent 1 routes, Agent 2 reasons (clinical
  and grief only), Agent 3 writes, Agent 4 reviews for safety. Routes: general support, clinical,
  grief, crisis, off-topic.
- Database: the Held app's own PostgreSQL tables. Writes ChatSession and ChatMessage; reads User,
  UserDisease, Disease, GriefNote and Mood. No migrations, no tables of its own, never adds users.
- Sign-in: every request needs a Held access token, verified with JWT_SECRET (or confirmed by
  Held's GET /auth/me). Guest mode (AUTH_DISABLED) is gone.
- Reply modes: myself / caregiver x diagnosed / undiagnosed, from the profile tool (User,
  UserDisease, Disease), read once per chat. "I", "me" and "my" always mean the user.
- Scope: anything outside mental health, wellbeing, caregiving and grief gets a short fixed reply
  (space, sport, coding, math, recipes...). Never in a chat where the user's own risk came up.
- Replies: ChatGPT-like formatting (short paragraphs, bold questions, bullets, numbered steps), no
  stock sympathy lines, no assumed gender or details, ambiguous words asked about.
- Token use per reply: stored in ChatMessage.metadata.usage; shown to the app only when
  SHOW_TOKEN_USAGE=true (off by default).
- Tests: 432 passed.

2. SAFETY
---------
- Instant crisis check before any AI call, in English, Spanish and Roman Urdu.
- Crisis protocol: thoughts of ending their life, then plan, access to means, timing, one
  question per reply; safety actions first in immediate danger; distance from the means; grounding
  only when it fits.
- Verified support lines (agent/backend/ai_wrapper/support_resources.py, SUPPORT_COUNTRY=US):
  988, 911, Poison Control 1-800-222-1222, National Domestic Violence Hotline 1-800-799-7233,
  Crisis Text Line (HOME to 741741), ANAD 1-888-375-7767, AFSP and Alliance of Hope. The agents
  may give no other number; code adds the crisis line to a chat's first crisis reply.
- Never unanswered: when Gemini fails (rate limit, outage), a message that may show risk gets a
  fixed crisis reply with 988 and 911 instead of an error.
- No lethal amounts, methods or ways to hide self-harm, however the request is framed.
- Says it is an AI, not a therapist, when asked.
- Two safety audits by the developer (19 Nov 2026, 63 scenarios, two accounts) were fixed and
  re-run live. Account isolation passed 20 of 20 checks.

3. GRIEF NOTES
--------------
- Notes are written in the Held app. The agent only reads them.
- In chat, Agent 3 may call three read-only tools when the answer needs the notes:
    recent_notes   the last N days (at most 90) and notes (at most 20)
    note_by_date   one date (YYYY-MM-DD)
    mood_summary   note count and mood frequencies, overall and by week
  The user comes only from the token; arguments are validated; 1,500 characters per note and at
  most 4 calls per message. Note text is data, never instructions; crisis language in a note
  takes the crisis path. Dates are UTC. Logs never hold note text.
- A note sent from the app with "isNote": true starts its own chat and gets a grief companion's
  reply. Its mood reaches the agent only if the app writes it into the prompt.

4. HOW CONTEXT MEMORY WORKS
---------------------------
- Same chat: the latest 20 messages, plus a rolling summary (up to 250 words) of older ones,
  updated in the background every 10 messages.
- New chat: starts fresh, with a short user memory (up to 150 words) as silent background.
- Recall: when the user refers back to an earlier chat, a full-text search over the last 365 days
  gives the writer the top 5 excerpts.
- Safety check-in: an earlier concern (last 6 days) is checked on once per account, only when the
  user talks about how they feel, never in a reply about a new loss.
- Memory is referred to tentatively; a "what do you remember" list leaves out abuse, suicidal
  thoughts and self-harm.

5. DEPLOYMENT
-------------
- Render (https://held-ai.onrender.com): this repository's main branch, manual deploy. Uses the
  testing Supabase database (Held app tables) and a paid Gemini key.
- Render environment: DATABASE_URL, GEMINI_API_KEY, JWT_SECRET (the key of the Held backend that
  issues the tokens). HELD_API_BASE_URL may be empty. SHOW_TOKEN_USAGE and SHOW_API_DOCS off.
- The private repository hashirflutter/held-ai-supabase holds the same code for local testing.

6. HOW TO RUN
-------------
  Settings: copy agent/.env.example to agent/.env (or .env at the root) and fill it in.
  Install:  cd agent ; ..\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
  Tests:    cd agent ; ..\.venv\Scripts\python.exe -m pytest -q
  Server:   cd agent ; ..\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
            (from the repository root: python -m uvicorn main:app)
  Swagger:  set SHOW_API_DOCS=true, then open http://127.0.0.1:8000/docs and Authorize with a Held
            access token (tokens last 15 minutes).
